安装指引

macOS

macOS 安装包已使用 Developer ID 签名并通过 Apple 公证，双击即可正常运行。

  1. 双击下载的 .dmg，把 Kimidance 拖入"应用程序"文件夹；
  2. 在"应用程序"中双击 Kimidance 即可使用。安装包已通过 Apple 公证，无需在系统设置中手动放行。

Windows

已经装过 0.4.8 的老用户：直接安装本版即可，不需要先卸载。0.4.8 升级时会报 0x80070002 的问题已在本版修复。你的成品文件目录不受影响。
装的是 0.2.x 或更早版本的老用户：请先卸载旧版本，再安装本版。免卸载升级只在 0.4.8 上验证过，0.2.x 及更早不在其列。卸载方法：打开"设置 → 应用 → 已安装的应用"，找到 Kimidance，点卸载；完成后确认文件夹 %LOCALAPPDATA%\Programs\Kimidance 已不存在，再运行新安装包。卸载不会删除你的成品文件目录，但仍建议先备份。首次安装的新用户不受影响，直接往下看。

Windows 安装包没有购买代码签名证书，所以首次运行时系统会拦一次。这是一个"系统不认识这个发布者"的提示，不是说文件有问题——你可以先用下面的 SHA-256 核对，确认下载到的就是官方文件，再按下面三步安装。

  1. 双击下载的 .exe；
  2. 如果出现蓝色的"Windows 已保护你的电脑"窗口，点左下角"更多信息"，再点"仍要运行"；
  3. 按提示完成安装，桌面和开始菜单会出现 Kimidance 图标。

绝大多数 Windows 10 / 11 电脑双击即装，全程不需要管理员权限，程序装在当前用户目录下（%LOCALAPPDATA%），不影响这台电脑上的其他账号。

少数被精简过的系统——例如某些企业定制镜像、LTSC 精简版——缺少 Microsoft Edge WebView2 运行时，安装包会自动补装它，这一步需要管理员权限，系统会弹出授权提示。如果你的账号本身是管理员，点"是"即可；如果不是，可以：

  • 请管理员在弹窗中输入密码；或
  • 先自行安装 Microsoft Edge WebView2 Runtime（微软官方，免费），装好后再运行 Kimidance 安装包，就不会再出现这一步。

校验安装包完整性

下载完成后可比对 SHA-256 校验值，确认文件与官方发布完全一致。Windows 用户建议做一次——安装包未签名，这是你自己确认"下载到的确实是官方文件"最直接的办法。 

# macOS（终端）
shasum -a 256 ~/Downloads/Kimidance-Mac-0.4.10-arm64.dmg
# 应输出：f97d4ff36427db02d2d1e62fae0335473dab63f7394a69c48a70a75d6e405d0c
# Windows（PowerShell）
Get-FileHash -Algorithm SHA256 "$env:USERPROFILE\Downloads\Kimidance-Windows-Setup-0.4.10-r15-x64.exe"
# Hash 应为：bc1204c181ffa5721789e0042ea28e5f0da0df3bf270fbb90335458ad3fd3d0e

PowerShell 输出的是大写，网页上是小写，大小写不影响，逐位一致即可。对不上就别装，重新下载或来邮件问我们。

常见问题

积分是什么？用完了怎么办？

登录后可查看积分和积分流水。新建单视频任务时，App 会先给出费用预估并等待确认；需要更多积分时，可在 App 内从三档套餐中选择，并使用微信扫码充值。

支持 Intel 芯片的 Mac 吗？

当前 macOS 版本仅支持 Apple Silicon（M1 及以后），不支持 Intel Mac。

Windows 为什么会弹蓝色警告？安全吗？

因为我们暂时没有购买 Windows 代码签名证书。SmartScreen 对所有未签名、下载量还不大的程序都会给这个提示，它表达的是"系统不认识这个发布者"，不是"检测到病毒"。判断文件是否可信，用上面的 SHA-256 核对最可靠。我们会在下载量积累后评估是否购买证书。

杀毒软件报毒 / 直接删掉了安装包怎么办？

未签名的新程序偶尔会被误判。请先核对 SHA-256，确认无误后在杀毒软件里把该文件或 Kimidance 安装目录加入信任（白名单），再重新安装。如果你不确定，把报毒的软件名称和提示截图发邮件给我们。

公司电脑装不了，要给 IT 什么信息？

通常提供这些就够 IT 加白名单：程序名 Kimidance（积米律动）；安装包 Kimidance-Windows-Setup-0.4.10-r15-x64.exe；SHA-256 bc1204c181ffa5721789e0042ea28e5f0da0df3bf270fbb90335458ad3fd3d0e；安装位置为当前用户目录 %LOCALAPPDATA%\Programs\Kimidance，不写系统目录、不安装驱动或服务；运行时仅访问我们的服务端 api.kimidance.com（HTTPS）。

怎么卸载？

"设置 → 应用 → 已安装的应用"里找到 Kimidance，点卸载即可；卸载不会删除你的成品文件目录，但仍建议先备份。
