方法论与口径

  • 数据由积米律动 AI 拉片 pipeline 生成：对完整视频逐镜头标注时长、景别、运镜、情绪与叙事功能。
  • 本页所有数字由脚本从原始分镜表自动重算；只汇总完整全片，片段单列不入汇总；汇总之下按类型（真人 / AI 漫剧 / 3D 动漫）给分型子行。
  • 聚合口径为镜头加权（不是按部平均）。
  • 每分钟切镜次数按各片 60 秒窗口取中位：丢掉末尾不足 60 秒的窗口，数每个窗口内起始的镜头数，全部窗口合并取中位。
  • 类型与画幅依据：画幅 = ffprobe 读取本机源片分辨率；类型 = 公开页面（表中链接）+ 抽帧目检。
